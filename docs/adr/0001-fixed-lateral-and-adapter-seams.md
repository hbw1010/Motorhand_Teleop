# 用 WujiRetarget 推断侧摆并隔离硬件适配器

手套只有屈伸自由度，WujiHand2 还包含四个指 MCP 侧摆自由度。项目不再维护手写12→20关节映射，而是把 vE3.3 闭链模型生成的21个任务点交给官方 WujiRetarget，由几何优化器推断完整 Hand2 姿态。

侧摆仍然不是手套的直接观测量：第一版只把它视为基于任务点的估计结果，并在诊断中显式标记；必要时可通过配置锁定或降权。控制核心只依赖抽象的状态/命令接口，Wuji 与手套 SDK 放在适配器 seam 后。这样离线重定向、仿真和回放可以先验证，真机轴序、零点、电流到力矩标定和硬件安全策略不会被错误的 SDK 假设污染。

## Consequences

- 正常链路是“12独立角 -> 闭链21点 -> WujiRetarget -> 20目标”，不允许新增直接关节映射旁路。
- 力反馈使用完整重定向链路的 `J_retarget.T`；当前通过独立求解器低频中心差分获得。
- 力反馈默认关闭，只有完成单机标定后才允许生成手套电流命令。
- 后续增加侧摆传感器时可以替换任务点源或优化器约束，不需要改硬件适配器 seam。
