# WujiHand2 力反馈手套开发计划

## 已确定的工程边界

- vE.3.3 的12个独立坐标先经闭链运动学生成21个任务点，再交给官方 `wuji-retargeting` 求解 Hand2 的20个目标；不维护手写12→20关节映射。
- 手套没有侧摆传感器：正向通过 `retarget.fixed_joints` 将四指 MCP 侧摆固定0；实测 Wuji 侧摆仍保留在 FK 中，不能篡改为0，也不能声称手套反解复现了侧摆。
- 只在硬件适配器之后使用 Wuji SDK；默认离线模型路径不连接硬件。
- Wuji `effort/current` 单位是 A。未经单机标定不得当作 N·m、指尖力或接触力。
- 真机首次动作必须按序列号绑定、按 nid 重建状态、确认20关节在线，并有应用层 watchdog 和显式急停流程。

### M1 仿真验收边界

- 仿真使用官网 Control Guide 的保守示例 `kp=3.0`、`kd=0.05`、`effort_limit=1.5 A`，设备硬上限 `2.0 A` 只作为安全检查边界。
- 仿真通过显式外力扰动 Hand2 指尖，读取 MuJoCo 广义外力作为“理想传感器”，经过假设的 A→N·m 常数、完整 `J_retarget.T` 和 vE3.3 传动雅可比生成手套电流。
- 仿真 A→N·m、手套电机力矩常数和人手保持刚度都是假设，不是官网参数，不得直接复制到真机。
- 当前无硬件验收配置使用 `feedback_jacobian_step_rad=0.01`、`feedback_gain=0.10`，仅用于数值稳定和安全闭环观察，不能当作真机标定值。

## 硬件未到前可做的事

1. 用两侧 vE.3.3 资产验证21点顺序、坐标变换、闭链残差和输出连续性。
2. 用官方 WujiRetarget 离线求解 Hand2 20维目标，调节旋转、骨段尺度、损失权重和侧摆推断约束。
3. 对录制/合成手套输入测量优化器延迟、收敛、限位和侧摆推断范围。
4. 用 WujiHand2 URDF/MuJoCo 做指尖任务误差、碰撞和可达性分析。
5. 低频计算并验证完整 `J_retarget`；再与手套闭链传动雅可比串联。
6. 设计并填写真机标定记录格式：SN、版本、轴序、零点、符号、限位、电流—力矩曲线、温度和失败原因。
7. 先做手套端低压/空载的独立电机测试；不要连接 Wuji 真机做未知映射的双端闭环。
8. 用假 Encos backend 验证角度单位、限位、MIT 电流限幅和推理/接管双端数据流；不连接真实电机时禁止调用 `encos-test`。

## 首次真机禁止项

- 禁止按数组位置猜 `S1..S4` 与 URDF 关节的对应关系。
- 禁止把 `effort/current` 直接转换成指尖力。
- 禁止在无 watchdog、无急停演练、无状态新鲜度检查时使能。
- 禁止把重定向器推断出的侧摆写成手套已经测量到的侧摆自由度。
