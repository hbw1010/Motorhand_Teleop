# Wuji→手套六组验证曲线实施计划与验证结果

> 用户已批准执行。2026-11-13：软件实现与离线验证完成；真机只读确认Wuji右手及固件2.13.1，手套USB网关暂未被系统识别，单指受阻实验待连接恢复后进行。

**目标：** 验证受阻后手套阻挡位置、强度、时序、保持与释放；不以两侧电流成比例作为准确性标准。
**范围：** 新监视UI、只读遥测与分析；不改变反馈计算、PD参数、限幅、现场零位和旧仿真UI。
**技术：** 复用PyQt/C++全采样绘制、冻结快照、A/B游标与JSONL导出。
**依据：** 用户2026-11-13提供的六组曲线规格。

- [x] ① Wuji受阻：目标/实际角同图叠对应关节受阻状态；速度、电流按各自单位与同一时间轴排列，同时区分锁存状态与实际参与求解状态。
- [x] ② 手套阻挡：同一原始电机坐标中显示实际角、代理参考角、最终下发目标角；另显示保护原因与参考来源时刻。
- [x] ③ 力矩输出：名义输入Nm与实测电流A分轴或上下对齐；默认不把空载5.1Nm/A参考称为独立标定。只有声明了有效标定及来源的通道才显示验证用力矩估计。
- [x] ④ 力矩/电流—偏差：横轴为沿阻挡方向超过代理参考的角度，按入/回开分色。未标定时纵轴A、斜率A/rad；有独立依据时才使用Nm/rad。名义理论线只作参考。
- [x] ⑤ 接触/释放时序：按真实软件事件与测量时间展示建立、撤除；保留A/B选点，不把收包→提交耗时当作完整触觉响应延迟。
- [x] ⑥ 保持/往返：查看角度、参考、力矩和电流的保持段与往返段；用选区统计漂移、峰峰值和波动，按实际速度方向区分按入/回开，不猜测人手意图。

## 3. 分析与标定边界

- [x] 支持冻结选区分析和保存快照，统计与画图严格使用同一份数据；不覆盖暂停数据，不平滑或补造缺失样本。
- [x] 刚度拟合只使用低速、有效受阻且未限幅的区间，显示筛选条件、样本数和单位。
- [x] 名义力矩与独立力矩估计的偏差/RMSE/峰值误差，仅在有效独立标定存在且时间匹配时计算；默认没有依据则显示不可用。
- [x] 不同时间源匹配需显示策略和允许时差；不使用未来样本制造响应，不把同公式重算结果当作执行准确性证据。

## 审查重点

代理参考不是最终目标；原始电机角不是模型指节角；接触时角差不是天然故障；锁存contact不等于实际impedance_contact；5.1空载参考不等于独立力矩标定；软件提交不是实际执行。

## 本轮结果

- Python监视/分析/交互/后端回归106项通过；原生离线12项通过。
- 1000帧修改前后规划输出共1,422,826字节一致；5类×12轴PTY编码及名义输出共7,286字节一致。解算、PD、摩擦补偿和限额未因增加观测而改变。
- 原有9个UI源码文件SHA256与开始修改时完全一致。
- 1700×1180、50Hz合成输入、新默认①页：5秒历史窗3D 58.9FPS；60秒历史窗3D 58.8FPS。60秒窗每次曲线绘制均值1.50ms、P95 1.84ms，保持3000帧全部数据。这是指定布局的离线性能结果，非所有页面/设备的保证。
- 截图核验①④⑥；真实Qt测试覆盖框选、A/B、暂停后新会话、反向轴散点、选区导出与原快照重算一致。
- 硬件仅运行发现/身份固件读取；未使能、回零或输出力反馈。当前无法进行双侧实机验收：系统未出现手套ttyUSB/ttyACM设备。
