# 独立遥操作监视 UI 实施计划

> 执行方式：superpowers:executing-plans，在当前会话逐项执行。用户已要求直接实现首版，不再等待设计确认。

**目标：** 新增可运行的双手三维与力反馈曲线监视窗口，原 UI 不变。
**架构：** UDP 只读接收、独立历史状态、MuJoCo 渲染子进程、Qt 窗口；控制端仅补充遥测。
**技术栈：** Python 3.12 / PyQt5 / MuJoCo 4 / C++17。
**设计：** ../specs/2026-11-12-teleop-monitor-design.md

## 全局约束
- 原仿真、viewer、force_curves UI 文件不修改。仅新增 pixi task。
- 不自动启动硬件，演示数据明确标识，缺失姿态不得伪装实测。
- 复用当前工作区已有未提交资产与驱动，原地新增，不重置/提交用户变更。

## 验证重点
- 新会话与乱序包：不混合曲线，旧会话不覆盖新会话。
- 断流和暂停：保留历史且区分历史/当前，不冻结新鲜度提示。
- 姿态缺失或非有限：拒绝坏包，不把默认零姿态显示为实测。
- 渲染进程失败：曲线仍工作，窗口可关闭，子进程释放。
- 扩展遥测：旧协议仍可解析，新增完整树维度68，状态事件不假称停机确认。
