# 独立遥操作监视 UI 第一版

用户要求：参考现有手套仿真，显示 Motorhand 与 Wuji Hand 2 状态和力反馈曲线；明确不要动原有 UI，已授权直接执行第一版。

新增 `teleop-ui` 独立入口，使用现有 PyQt5、MuJoCo 和模型资产。界面为深色桌面窗口：双手实测三维姿态、Wuji 半透明目标叠影；按手指切换名义反馈力矩、两侧实测电流、Wuji 目标误差曲线；显示数据时效、频率、接触状态和停机原因。支持暂停显示、视角调整、保存当前历史、无硬件演示。仅右手。

方案比较：扩展旧窗口改动少但违背用户保留旧 UI 的约束；全新桌面监视器保持独立并复用资产和遥测协议，因此采用后者。集成控制按钮需要设备生命周期管理，不纳入第一版。

UI 不连接 SDK、不启动或停止硬件。旧 UI 文件与既有启动任务不改。控制端仅向原 UDP 遥测增加完整手套树、闭环间隙和侧别字段，并发送生命周期事件；旧数据字段与控制算法不变。三维直接使用控制侧已求解的树，不在 UI 重算闭链。掉线/停机后保留最后有效画面并明确标记，缺失值不补零，图表不连接跨会话或断流数据。

闭链越分支故障继续走原停机保护；UI 用于观察，不宣称修复了该故障。SDK编码器/堵转报警仍在控制终端，第一版显示控制停机原因和接触估计。
